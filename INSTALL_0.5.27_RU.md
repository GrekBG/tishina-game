# Установка ТИШИНА 0.5.27

1. Скачайте архив `TISHINA_0.5.27_FULL_REPLACEMENT.zip`.
2. Распакуйте архив. Внутри находится папка `tishina-game-main`.
3. В GitHub откройте репозиторий `GrekBG/tishina-game`.
4. Замените содержимое репозитория файлами из этой папки, сохраняя структуру каталогов.
5. Убедитесь, что в репозитории есть `assets/road-damaged/` с пятью JPG:
   - `road-damaged-albedo.jpg`
   - `road-damaged-normal.jpg`
   - `road-damaged-roughness.jpg`
   - `road-damaged-ao.jpg`
   - `road-damaged-displacement.jpg`
6. Дождитесь завершения публикации GitHub Pages.
7. На iPhone откройте игру и обновите страницу. Если старая версия остаётся, закройте вкладку игры и откройте её заново.

Главная страница: https://grekbg.github.io/tishina-game/

Важно: это полная замена файлов проекта, а не точечный патч. Не удаляйте папки `src`, `assets` и игровые модели.
