# Установка ТИШИНА 0.5.13

В корне репозитория должны лежать `index.html`, `service-worker.js` и `lod0.glb`, а в папке `src` — обновлённый `main.js`.

Для обновления:
1. Замените `index.html`, `service-worker.js` и `src/main.js` файлами из архива.
2. Добавьте `lod0.glb` в корень репозитория рядом с `index.html`.
3. Добавьте файл `CHANGELOG_0.5.13_RU.md`.
4. Сделайте commit в ветку `main`.
5. Откройте игру и обновите страницу. Версия 0.5.13 использует отдельное имя кэша.

Если модель не загрузилась, процедурный ангар останется на месте — игра не должна оставаться без здания.
