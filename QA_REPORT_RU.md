# ТИШИНА 0.4.5 — отчёт проверки патча

## Проверено по текущему GitHub main
- В опубликованном `src/main.js` уже есть прямой `offerItem(id)`: предмет добавляется в инвентарь при одном нажатии; при переполнении инвентаря остаётся в мире.
- В опубликованных `index.html` и `src/main.js` нет `itemChoice` и `itemExamine`.
- Текущий `src/main.js` обращается к `expansion.evacuationLog`; патч `src/world-expansion.js` сохраняет этот объект и возвращает `update()`.
- Все 64 уникальных HTML ID, к которым обращается опубликованный `src/main.js`, существуют в подготовленном `index.html`.

## Проверено локально в патче
- `src/world-expansion.js` и `service-worker.js` проходят `node --check`.
- Встроенные JavaScript-блоки `index.html` проходят `node --check`.
- COLLADA-файл корректно разбирается как XML 1.4.1; в модели обнаружены 42 геометрических узла и 16 material slots.
- DAE ссылается на `uaz-body.webp` и `uaz-details.webp`; оба файла находятся рядом с `uaz.dae`.
- Обе текстуры — 3000×3000 пикселей. Разрешение не уменьшено.
- `ColladaLoader` импортируется через `three/addons/` из import map; URL модели рассчитывается относительно `src/world-expansion.js` и указывает на `../uaz.dae` в корне сайта.
- Коллизия автомобиля создаётся из фактического bounding box загруженной модели.
- Ключ кэша страницы и Service Worker совпадает; DAE и обе текстуры входят в APP_SHELL.
- ZIP-архивы открываются и содержат ожидаемые пути.

## Ограничения
- Это статическая и структурная проверка. Полноценный рендер WebGL, фактический масштаб/ориентацию модели и скорость загрузки на физическом iPhone нужно подтвердить в Safari после публикации.
- В архиве `UAZ-buhanka.zip` не найден файл лицензии. Права на публичное и коммерческое распространение модели не подтверждены.
