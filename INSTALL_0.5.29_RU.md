# Установка ТИШИНА 0.5.29

Распакуйте архив и перенесите содержимое папки `tishina-game-main` в корень репозитория GitHub с заменой файлов.

После публикации откройте игру в Safari и обновите страницу. На старом сохранении можно нажать «Продолжить игру»; для чистой проверки лестницы рекомендуется начать новую игру.

Подъём теперь выполняется автоматически: просто двигайтесь вверх по обычной лестнице. Отдельная кнопка взаимодействия для лестницы больше не нужна. Максимальная высота одного шага — 0,30 м.
