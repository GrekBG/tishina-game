# Установка ТИШИНА 0.5.28

1. Распакуйте архив.
2. Загрузите содержимое папки `tishina-game-main` в корень репозитория GitHub Pages с заменой одноимённых файлов и папок.
3. Дождитесь завершения публикации GitHub Pages.
4. На iPhone откройте игру и обновите страницу. Если Safari показывает прежнюю версию, закройте вкладку игры и откройте её заново.

В этой версии наружная площадка представляет собой единое асфальтовое поле размером 1000 × 1000 м. Доступная область перемещения — примерно 996 × 996 м с небольшим отступом от края покрытия.
