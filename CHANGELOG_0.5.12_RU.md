# ТИШИНА 0.5.12 — старт в полдень, главное меню и подбор предметов

## Время начала
- Новая игра начинается в 12:00 игрового времени. Загруженные сохранения продолжают использовать сохранённое время.

## Стартовое меню
- В стартовом меню доступны: «Продолжить игру», «Новая игра», «Загрузить сохранение», «Сохранить игру», «Выход».
- Состояние кнопок продолжения и загрузки синхронизируется с локальными сохранениями.
- На коротких альбомных экранах меню прокручивается, не обрезая кнопки.
- Выход из браузерной игры показывает подсказку закрыть вкладку: мобильный браузер не разрешает странице закрыть себя программно.

## Подбор предметов
- Взаимодействие с предметом открывает постоянную карточку с названием, типом, описанием и весом.
- Предмет не подбирается автоматически.
- Отдельная кнопка «ВЗЯТЬ» добавляет предмет в инвентарь и закрывает карточку.
- Карточку можно закрыть крестиком без подбора. При переполнении инвентаря кнопка заблокирована.

## Проверки
- Проверка синтаксиса всех JavaScript-файлов через Node.js.
- Проверка наличия всех обработчиков меню и карточки предмета.
- Проверка целостности патч-архива.
- Реальный запуск на iPhone/Safari требует проверки после публикации.
