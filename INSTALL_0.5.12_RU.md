# ТИШИНА 0.5.12 — установка обновления

## Изменения
- Новая игра начинается в 12:00.
- В стартовое меню добавлены действия продолжения, загрузки, сохранения и выхода.
- При наведении на предмет кнопка взаимодействия открывает карточку с описанием.
- Предмет добавляется в инвентарь только после нажатия «ВЗЯТЬ».
- Карточку можно закрыть крестиком или клавишей Escape, не подбирая предмет.

## Обновление через GitHub на iPhone
1. Распакуй `TISHINA_0.5.12_patch.zip` в приложении «Файлы».
2. В репозитории `GrekBG/tishina-game` замени `index.html` и `service-worker.js` в корне.
3. Открой папку `src` и замени `main.js` и `sky-weather.js`.
4. Сохрани изменения коммитом в ветку `main`.
5. После обновления GitHub Pages открой игру по ссылке с новым параметром `?v=0512`.

## Поведение меню
- «Продолжить игру» доступно, если на устройстве есть автосохранение.
- «Загрузить сохранение» доступно, если есть отдельное ручное сохранение.
- «Сохранить игру» записывает текущее состояние на этом устройстве.
- «Выход» возвращает к стартовому экрану. Чтобы закрыть Safari-вкладку, пользователь закрывает её средствами браузера.

## Проверки
JavaScript-файлы проверены `node --check`; HTML проверен на повторяющиеся ID. Перед использованием на телефоне нужно проверить работу кнопок и подбор предметов в Safari.
