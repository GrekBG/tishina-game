# ТИШИНА 0.5.0 — исправление подключения ангара

## Что исправлено
- `src/main.js` больше не загружает ангар с внешнего CDN `cdn.3dassets.dev`.
- Модель загружается локально из корня сайта: `../hangar.glb` относительно `src/main.js`.
- Добавлен параметр версии `v=050` для обхода старого кеша браузера.
- `service-worker.js`: обновлено имя кеша до `tishina-0-5-0-local-hangar-glb`.
- `index.html`: версия в заголовке и стартовом меню синхронизирована на 0.5.0.
- Сам `hangar.glb` не изменён и должен оставаться в корне репозитория.

## Проверка ассета из исходного архива
- Файл `hangar.glb` присутствует, размер 24 663 816 байт.
- GLB v2, 7 mesh-объектов, 7 материалов, 2 текстуры.
- По данным GLB: 73 799 вершин суммарно; 365 196 индексов треугольников (121 732 треугольника).
- Габариты из метаданных: 18.3 × 6.974 × 16.52 м; оболочка заявлена как закрытая.
- Это не сетка 10 000 × 10 000 вершин: такая сетка была бы чрезмерно тяжёлой для iPhone. В модели уже есть достаточно плотная геометрия для браузерной игры.

## Какие файлы заменить
1. `src/main.js`
2. `index.html`
3. `service-worker.js`

Не удалять и не переименовывать `hangar.glb` в корне репозитория.

## Важно
Это исправляет путь загрузки модели. Автоматически проверить визуальный результат в реальном Safari/WebGL из ZIP нельзя; после публикации нужно открыть игру с новым параметром `?v=050` и проверить ангар в самой сцене.
