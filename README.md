# ТИШИНА — прототип 0.1

Это статическая веб-игра, подготовленная для GitHub Pages.

## Публикация
1. Создайте публичный репозиторий `tishina-game`.
2. Загрузите все файлы из этой папки в корень репозитория.
3. В Settings → Pages выберите Deploy from a branch → main → /(root) → Save.
4. После публикации откройте выданный GitHub Pages URL в Safari на iPhone.
5. В Safari нажмите Поделиться → На экран Домой → Добавить.

Файлы включают manifest и service worker для установки на главный экран и базовой офлайн-работы после первого открытия.
