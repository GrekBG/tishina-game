# ТИШИНА 0.4.6 — импортированная модель УАЗ-452

## Что меняется
- Внешний мир использует предоставленную пользователем текстурированную модель УАЗ-452 из `UAZ-buhanka.zip`.
- Модель читается через Three.js `ColladaLoader` из `uaz.dae`.
- Две исходные UV-текстуры сохранены в WebP по 3000×3000 пикселей без уменьшения разрешения.
- Коллизия автомобиля рассчитывается по фактическим границам загруженной модели.
- Удалён режим вращения предмета в руках и промежуточный выбор «осмотреть / в инвентарь / оставить».
- Найденные предметы подбираются сразу одной кнопкой взаимодействия; при полном инвентаре предмет остаётся на месте.
- Сохранены актуальные игровые модули, включая текущий `src/main.js` с загрузчиком GLTF для ангара.

## Формат ассета
Исходный архив содержал `uaz.dae`, `uaz.obj`, `uaz.3ds`, `uaz.stl` и две PNG-текстуры. В COLLADA-файле сохранены 42 геометрических узла и 16 слотов материалов. Для браузерной версии выбран DAE с явными UV/material references.

## Текстуры
- `uaz-body.webp` — 3000×3000.
- `uaz-details.webp` — 3000×3000.
- Формат PNG заменён на WebP качества 90, разрешение не уменьшено.

## Лицензия
В исходном ZIP не обнаружен отдельный файл лицензии. Право на публичное и коммерческое распространение пока не подтверждено; перед коммерческим релизом нужно установить условия использования ассета.

## Обновление через GitHub на iPhone
1. Загрузить содержимое `root-files.zip` в корень репозитория и сделать коммит.
2. Загрузить `src/world-expansion.js` из `src-patch.zip` в папку `src` с заменой существующего файла и сделать второй коммит.
3. Открыть игру с параметром `?v=045` и проверить модель в Safari.

`src/main.js` и остальные текущие игровые модули намеренно не заменяются этой заплаткой, чтобы сохранить текущие изменения в GitHub.
