# ТИШИНА 0.5.19
- Заменены грубые прямоугольные коллизии ангара на столкновения по треугольникам реальной GLB-геометрии.
- Коллизии строятся отдельно для каждой треугольной грани конструктивных деталей; проёмы остаются открытыми, поскольку в них нет геометрии.
- Добавлена пространственная сетка 1×1 м для ускорения проверки коллизий на мобильных устройствах.
- Процедурное небо теперь получает значение дневного освещения непосредственно от игрового времени.
- Синхронизированы версия страницы и имя кэша Service Worker.
