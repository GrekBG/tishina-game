# Установка ТИШИНА 0.5.30

1. Распакуйте архив.
2. Откройте папку `tishina-game-main`.
3. Замените в GitHub содержимое репозитория всеми файлами из этой папки, сохраняя структуру каталогов.
4. Дождитесь окончания публикации GitHub Pages.
5. На iPhone закройте вкладку игры полностью, затем откройте https://grekbg.github.io/tishina-game/ заново.

В версии 0.5.30 исправлен ключ кэша и добавлены версии к адресам JS-модулей, чтобы старый код не загружался повторно. После установки проверьте, исчезла ли плашка «Техническая лестница». Если она исчезла, сразу испытайте подъём по ступеням, просто двигая стик вперёд.
