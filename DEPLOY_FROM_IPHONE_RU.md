# Установка патча ТИШИНА 0.4.5 с iPhone

Это точечное обновление поверх текущего GitHub `main` 0.4.4. `src/main.js`, PBR, сюжет и погода не заменяются: в опубликованном `main.js` уже есть подбор предметов одним нажатием и отсутствует режим осмотра предмета.

## Шаг 1 — корень репозитория
1. Скачай и распакуй `tishina-game-v0.4.5-root-files.zip`.
2. Открой GitHub → `GrekBG/tishina-game` → Add file → Upload files.
3. Загрузи 8 файлов из распакованной папки прямо в корень репозитория: `index.html`, `manifest.webmanifest`, `service-worker.js`, `icon-192.png`, `icon-512.png`, `uaz.dae`, `uaz-body.webp`, `uaz-details.webp`.
4. Сделай коммит напрямую в `main`.

## Шаг 2 — модуль внешнего мира
1. Скачай и распакуй `tishina-game-v0.4.5-src-patch.zip`.
2. Открой папку `src` в репозитории GitHub.
3. Загрузи только `world-expansion.js`, замени существующий файл и сделай второй коммит в `main`.

## Шаг 3 — тест
Открой `https://grekbg.github.io/tishina-game/?v=045` в Safari в альбомном положении. Проверь УАЗ на площадке, столкновение с кузовом и подбор предмета одной кнопкой.

Не загружай ZIP-файлы как файлы проекта и не заменяй остальные модули `src`.
