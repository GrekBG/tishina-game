# ТИШИНА 0.5.1 — исправление ангара

## Причина
В `src/main.js` при успешной загрузке внешней GLB-модели скрывались все процедурные элементы оболочки ангара (стены, тентовая крыша, торцевые панели, каркас и ворота). Загруженная GLB-модель отображалась как открытый каркас, поэтому ангар выглядел незакрытым.

## Исправление
В `src/main.js` отключён вызов `loadHangarModel()`. Процедурная закрытая оболочка, уже построенная в сцене, больше не скрывается и остаётся видимой. Остальная игровая логика, УАЗ, двери, предметы и расширение мира не изменены.

В `index.html` обновлена версия до 0.5.1. В `service-worker.js` изменено имя кеша, чтобы Safari не использовал старую сборку.

## Замена
Заменить в GitHub:
- `src/main.js`
- `index.html`
- `service-worker.js`

Файл `hangar.glb` можно оставить в корне репозитория — новая версия его не подставляет вместо ангара.

## Проверки
- JavaScript синтаксис `src/main.js`: проверяется Node.js.
- JavaScript синтаксис `service-worker.js`: проверяется Node.js.
- ZIP целостность: проверяется после сборки.

Ограничение: реальный рендер в Safari на устройстве пользователя отсюда не запускается. После публикации нужно визуально проверить сцену.
